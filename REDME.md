# Reinhard Krahn GmbH – Website

Moderne Unternehmenswebsite für die Reinhard Krahn GmbH in Jülich.

Die Website wurde mit HTML, CSS und JavaScript erstellt und umfasst unter anderem:

- Responsive Unternehmenswebsite
- Slideshow auf der Startseite
- Leistungen im Bereich Metallbau, Montage, Instandhaltung und Kerntechnik
- Über-uns-Bereich
- Karrierebereich
- Galerie
- Kontaktinformationen
- Suchmaschinenoptimierte Titel und Meta-Beschreibungen

## Technologien

- HTML5
- CSS3
- JavaScript
